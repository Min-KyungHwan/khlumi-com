KeyDex 개인정보처리방침

케이에이치루미(KH Lumi)의 KeyDex 모바일 앱과 크롬 확장 프로그램에 관한 개인정보 처리 내용을 설명합니다. 회사 웹사이트 이용에는 웹사이트 개인정보처리방침이 적용됩니다.

적용 범위 처리 항목 저장·전달 방식 보유·파기 제공·위탁 이용자 권리 보호 조치

1. 적용 범위와 처리 목적

이 방침은 KeyDex 모바일 앱, 크롬 확장 프로그램, 두 기기의 연결에 사용되는 릴레이 기능에 적용됩니다. KeyDex는 이용자가 입력한 사이트별 계정 정보를 스마트폰에서 관리하고, 이용자가 승인한 경우 PC 로그인 화면에 정보를 입력하거나 PC의 입력값을 스마트폰에 저장하는 기능을 제공합니다.

2. 처리하는 정보와 수집 방법

기능관련 정보입력·생성 경로
모바일 금고사이트명·도메인, 로그인 ID 또는 이메일, 비밀번호, 로그인 방식, 카테고리·메모 등 이용자가 저장한 정보앱에서 이용자가 입력하거나 계정 등록·수정 QR을 승인
기기 연결QR 세션 정보, 연결 상태, 페어링에 사용되는 공개키앱과 확장 프로그램의 페어링 과정에서 생성
릴레이 세션세션 식별자, 업로드·다운로드 토큰, 만료 시각, 암호화된 응답의 일회용 공개키·초기화 벡터·암호문확장 프로그램의 세션 요청과 앱의 암호화된 응답 전달 과정에서 생성·전송

서비스 운영 기록IP 주소, 요청 시각·방식·URL, 응답 상태와 오류 정보 등 기술정보Cloudflare 릴레이 이용 과정에서 자동 생성될 수 있음

생체인증은 금고 잠금 해제와 민감 기능 승인에 사용됩니다. 인증은 기기 운영체제가 수행하며, KeyDex와 KH Lumi는 지문·얼굴 등 생체정보 원본을 수집하거나 보관하지 않고 인증 성공 여부만 확인합니다.

3. 기기별 저장과 정보 전달

  • 스마트폰: 계정 정보는 스마트폰 앱에 저장되고, 비밀번호는 암호화되어 저장됩니다. OS 자동완성 기능을 켜면 사용자가 선택한 계정 정보가 로그인 입력란에 제공됩니다.
  • PC 확장 프로그램: 페어링 공개키와 연결 상태를 관리합니다. PC에 계정 정보를 저장하지 않으며, QR 로그인 승인 후 로그인 양식에 ID·비밀번호를 입력합니다.
  • 계정 등록·수정 QR: PC 페이지의 입력값을 QR에 담아 앱으로 전달합니다. QR이 화면에 표시되는 동안 주변 사람이 보거나 촬영할 수 있으므로 취급에 유의해야 합니다.
  • 릴레이: 현재 로컬 구현은 Cloudflare Workers와 Durable Objects를 사용합니다. 확장 프로그램의 요청으로 세션 식별자, 업로드·다운로드 토큰과 만료 시각을 발급하고, 이후 URL의 세션 식별자와 인증 헤더의 토큰을 받아 암호화된 응답(일회용 공개키, 초기화 벡터, 암호문)을 일시적으로 보관·전달합니다. 릴레이 코드는 암호문을 복호화하지 않습니다. 로그인 QR의 사이트 도메인은 QR에 포함되지만 로그인용 릴레이 요청의 별도 필드로 전송되지는 않습니다.

4. 보유 기간과 파기 방법

스마트폰 금고의 계정 정보는 이용자 기기의 앱에 저장되며, KH Lumi의 서버에 계정 금고로 동기화하거나 지속 보관하지 않습니다. 이용자는 앱에서 저장된 계정을 수정·삭제할 수 있습니다. KeyDex 자체의 암호화 백업·복원 기능은 현재 제공하지 않습니다.

현재 로컬 릴레이 코드는 유효한 다운로드 요청에 암호화된 응답을 반환할 때 해당 세션 데이터를 삭제합니다. 세션은 발급 후 60초가 지나면 이용할 수 없고, 만료 후 요청이 들어오면 저장 데이터를 삭제합니다. 별도로 만료 5초 후 데이터 삭제 알람을 예약하지만 실제 실행은 지연될 수 있습니다. Cloudflare의 SQLite 기반 Durable Objects는 최대 30일 전 시점으로 저장소를 복구하는 기능을 제공하므로, 일반 세션 데이터의 삭제가 모든 복구 가능 데이터의 즉시 영구 삭제를 뜻하지는 않습니다.

5. 제3자 제공, 처리위탁 및 국외 이전

KH Lumi는 이용자의 개인정보를 제3자에게 판매하거나 광고 목적으로 제공하지 않습니다. QR 로그인 과정에서 이용자가 승인한 계정 정보는 이용자가 접속한 웹사이트의 로그인 양식에 입력되며, 이후 해당 웹사이트에서의 처리에는 그 사이트의 방침이 적용됩니다. Cloudflare는 데이터 처리 부속계약에 따라 KH Lumi를 대신하여 아래 업무를 처리합니다.
